# User Guide

## Overview

This application helps you discover movies based on your preferences using natural language descriptions. It uses advanced AI to understand your requests and provide personalized movie recommendations.

## Getting Started

1. Open the application in your web browser
2. You'll see a clean interface with a search bar at the top
3. Enter your movie preferences in natural language

## How to Use

### Making a Request

1. Type your request in the search bar. For example:
   - "I want to watch a movie about a female detective"
   - "Show me romantic comedies"
   - "I'm looking for a sci-fi movie with aliens"

2. Press Enter or click the search button

### Understanding Results

The application will show you:
- Movie cards with posters
- Basic information (title, release date, genres)
- A brief overview of each movie
- An explanation of why this movie was recommended

### Additional Features

- **Theme Toggle**: Switch between light and dark themes using the theme button
- **Accessibility Mode**: Enable high contrast and larger text for better readability
- **Explanation Toggle**: Click to show/hide the AI-generated explanation for each recommendation

## Tips for Better Results

1. Be specific in your requests
2. Mention genres, time periods, or specific elements you're interested in
3. Include your mood or the type of experience you're looking for
4. You can combine multiple preferences in one request

## Troubleshooting

### Common Issues

1. **No Results Found**
   - Try rephrasing your request
   - Make your description more general
   - Check your internet connection

2. **Slow Response**
   - The application might be processing a complex request
   - Check your internet connection
   - Try refreshing the page

3. **Error Messages**
   - If you see an error, try again in a few moments
   - Make sure your request is not too long (maximum 1000 characters)
   - Contact support if the issue persists
